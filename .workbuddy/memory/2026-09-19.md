### 关键坑（重要，下次直接复用）

1. **`resource_root()` 路径层数**：源码布局是 `<root>/src/backend/app.py`，
   要回退**三级**才到项目根。最初写成两级 → UI 路径变成 `src/src/ui/index.html`，
   数据目录跑到 `src/data`。这个 bug 是靠 pywebview 启动探测抓出来的。
2. **`collect_due_reminders` 的 `continue` 陷阱**：最初每个提醒节点命中后
   `continue`，导致同一任务的多节点（start/pre_end/end）在休眠唤醒后互相阻塞。
   改为「三节点独立判定 → 按紧迫度排序取最紧迫的一个」，既补偿又不连环轰炸。
3. **测试沙箱必须唯一**：复用固定目录会让上一轮残留数据污染断言
   （首轮出现「初始任务列表为空」失败）。改用带时间戳+pid 的目录名解决。
4. **Edge 无头截图有磁盘缓存**：相同 URL 二次截图会返回**完全相同的旧图**
   （文件大小一模一样是明显信号）。必须加 `--disk-cache-size=1` 且 URL 追加
   `&nocache=<时间戳>`，并用**新文件名**输出（旧文件删除会触发沙箱批量删除保护）。
5. **sandbox bash 缺 coreutils**：`ls`/`tail`/`mkdir`/`head`/`dirname` 全部不可用，
   只有 `cd`/`echo`/`for` 等内建命令可用。文件操作一律走 PowerShell 或 Python。
6. **`git rebase --onto` 在反斜杠路径下会毁掉 .git**：一次 `cd /e/1My_Files\.Project\HC-Note`
   被 shell 解析成 `/e/1My_Files.ProjectHC-Note`，rebase 在异常状态下把 `.git` 整个删了。
   源码无损，重新 `git init` + merge 远程历史即可恢复。**git 操作前务必确认 pwd 正确**。
7. **`.git` refs 写入受限**：沙箱下 `git fetch` 拿得到对象但不写 `refs/remotes`，
   `git checkout main` 会失败，需用 `git checkout FETCH_HEAD -- .`。
8. **PyInstaller `--distpath` 必须用绝对路径**，且 spec 里 `datas` 也要绝对路径
   （相对路径基准是 `--specpath`）。产物 20.73 MB，资源全部内嵌验证通过。
